# Yury Shirokov Personal Training

A static one-page website for ACE-certified personal training in the San Jose area and online by Zoom.

## Preview locally

Open `index.html` in a browser. No build step is required.

## Before publishing

- Test the email link in the contact section before launch.
- Add additional original coaching photos to `assets/` as you collect them. The current page uses the photo Yury provided.
- Add testimonials only after the client approves the exact quote and gives written permission.
- Confirm availability and payment process.
- Review all client documents with a California attorney and the relevant insurer.
- Set up secure, private client onboarding. Do not store completed health, emergency-contact, waiver, or consent forms in this repository.

## Client documents

Blank editable starter templates are in `docs/`. They are not legal or medical advice and are not ready for client use until customized and reviewed. The website does not collect health information.

## Deployment

This is plain HTML, CSS, and JavaScript and can be hosted with GitHub Pages or any static web host. Configure the host for the repository's `main` branch and root folder.
